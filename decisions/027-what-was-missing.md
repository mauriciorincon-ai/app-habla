# ADR 027 — What was missing: the device voice for an unrecorded pictogram, a build-generated precache and sensory load the adult tunes

- **Status:** accepted (2026-11-15, Sprint 015). The owner's G-Plan answer «1 a» applies as written: a
  pictogram nobody recorded **sounds with the device's own voice**, only voices that run on the device
  (`localService`), never a network voice. The family's recording always wins. With no local voice for that
  language it stays silent, and the Studio tells the adult what to record.
- **Bound by:**
  - Hard rule 1: deterministic first. The device voice is the operating system's offline speech engine, not
    generative AI and not a paid API.
  - Hard rule 2: the child's audio is never stored and never leaves. The service worker never caches audio,
    the recognizer or anything from the microphone. The device voice only speaks app text.
  - Hard rule 3: the celebration only says what was measured in their turn.
  - Hard rule 6: no time limit, no game-over. Sensory load is adjustable.
  - Rule 23: the date is a knob (the daily surprise).

## Context

The VISION → code matrix of 2026-11-15 found seven sub-promises half-kept. Three of them needed a decision
that outlives the sprint; this ADR records those three. The other four (twin words inside the common frame,
three recordable invitations, the calm toggle in Today and twin words, the surprises) are UI over existing engines
and live in the manual.

## Decision

### 1. The pictogram always sounds

- `src/lib/audio/sonido-palabra.ts` (pure) decides the source of a word:
  1. the family recording, when it exists and «Use the family's voice» is on;
  2. otherwise the **device voice**, when a voice with `localService === true` speaks the screen language and
     «App sounds» is not off;
  3. otherwise nothing.
- `src/lib/audio/voz-aparato.ts` is the **only** file in `src/` that touches `speechSynthesis`.
  - It picks the voice object again from the system list and requires `localService === true` on the object
    it hands to `speak`.
  - It calls the meter guard (`alSonar`) before speaking, so the device voice's echo never counts as the
    child's voice (ADR-010).
- `tests/unit/sonido-palabra.test.ts` checks three things: only that file uses the API, a network-only list
  stays silent, and the adapter imports nothing from the microphone, storage or the network.
- **Why not a network voice:** a network voice sends the text to a third party. The text is only the app's
  word, but the promise «nothing leaves» must not depend on what the text is.

### 2. Offline for real: the precache is generated by the build

- After `next build`, `scripts/gen-precache.mjs` reads `.next/BUILD_ID` and the prerendered HTML of every own
  route a family opens without a network:
  - Today and `/jugar`;
  - the seven games;
  - Cuentos and Ajustes.
- From that HTML it collects the hashed `/_next/static/` files, then follows the chunk graph transitively, so
  dynamic imports are included.
- It adds the worklets, the pictograms, the icons and the manifest, and writes `public/sw-precache.js`
  (git-ignored).
- `public/sw.js` loads that list with `importScripts`. The cache is named after the build id, so a deploy
  installs a new cache and drops the old one. Navigation stays network-first.
- `scripts/precache.mjs` (pure) refuses audio extensions, `/modelos/` and `/vosk/`, so the worker can never be
  told to cache them. At run time `public/sw.js` also lets any audio request (`wav`, `mp3`, `ogg`, `webm`,
  `m4a`, `aac`, `opus`, `mp4`) pass without touching it; `tests/unit/precache.test.ts` reads the worker and
  asserts that guard.
- `tests/e2e/sin-red.spec.ts` (under `next start`) visits `/` once, cuts the network and reloads every route.
- **Size:** about 45 chunks plus 83 pictograms (≈ 3 MB) on the first visit. Accepted: the games are useless
  offline without their pictograms.

### 3. Sensory load the adult tunes

- `AjustesSchema` gains two settings, both read with `.catch` so older settings migrate:
  - `sonidos` (`normal | suave | apagado`), shown as «App sounds»;
  - `intensidad` (`normal | suave`), shown as «Colour intensity».
- **App sounds.** The app has no sound effects: the games that measure sound do not emit it, because the
  echo would come back through the microphone. So «App sounds» governs **the app's own voice**, the device
  voice: soft halves its volume and off silences it. The family's recorded voice keeps its own switch.
- **Colour intensity.** `data-intensidad="suave"` on `<html>` softens the palette of both registers.
  `tests/unit/contraste.test.ts` keeps it at AA.
- **The daily screen cap now counts what the child watches.** Cuentos and the video library count toward
  the cap through `useTopeAlTerminar`.
  - The notice **waits for the page or the clip to end**. A looping clip stops looping when the cap arrives
    and plays to its end.
  - The pure part is `topeLlego` / `unidadTerminada` in `src/lib/pantalla/tope.ts`.

### 4. The celebration speaks with the family's voice

- `claveCelebracion(metrica)` (`src/lib/banco-voz/celebracion.ts`) picks the recorded phrase from what was
  measured:
  - «casi» when nothing was heard (it now sounds for the first time);
  - «dijo-palabra» only when the adult marked the word;
  - «le-salio» when a voice was measured;
  - nothing for twin words with no marks.
- `CelebracionHonesta` plays that phrase once, only when it is recorded.

## Consequences

- An unrecorded word is no longer silent on a device with a local voice. On one without a local voice, the
  Studio says what to record.
- The first visit downloads the offline set. Later deploys replace it, never stack it.
- The settings stay on the device and never travel in the other-home package (`otra-casa.test.ts`).
